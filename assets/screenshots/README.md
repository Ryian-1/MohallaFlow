# MohallaFlow app screenshots

These are genuine captures of the running Flutter application from authenticated Admin, Resident, Cleanliness Manager and Worker sessions against the isolated demo-mohallaflow Firebase Emulator project.

The fixture uses fictional identities and synthetic contact values only. The resident complaint form omits malformed legacy phone data; the Worker task fixture uses the format-valid demo value 9000000000 because Firestore task validation requires a valid ten-digit mobile format. No production Firebase data is used.
