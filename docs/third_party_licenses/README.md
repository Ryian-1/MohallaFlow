# Third-party licence inventory

Generated from the Flutter/Dart licence report, npm dependency licence
reports, and exact iOS Swift Package Manager checkouts pinned by
`Package.resolved`.

CSV manifests map each package/version to its declared licence and retained
notice text. Text files are deduplicated by SHA-256 except for iOS files,
which preserve package and source-directory paths.

This folder does not grant a licence to MohallaFlow's own application code
or branding. See the root `THIRD_PARTY_NOTICES.md`.
