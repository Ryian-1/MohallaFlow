# Stage 6 — Mobile App Check and Monitoring

## Client configuration

FlutterFire versions selected from Firebase Flutter BoM 5.1.0 (22 October 2026):

- `firebase_app_check` 0.5.1
- `firebase_crashlytics` 6.0.1
- `firebase_performance` 0.12.1

On Android release builds MohallaFlow uses Play Integrity. On iOS release builds it uses App Attest with DeviceCheck fallback. Debug builds use the App Check debug provider, and the generated debug token must be registered in Firebase Console for the corresponding app. Never ship a build with the debug provider.

Crashlytics and Performance Monitoring collection are disabled in debug and enabled in release. Flutter framework fatal errors and uncaught asynchronous release errors are forwarded to Crashlytics. No forced test crash is included.

## Android Gradle plugins

The Android app adds Crashlytics Gradle plugin 3.0.8 and Performance Monitoring plugin 2.0.2. Google Services plugin is raised to 4.5.0 to satisfy current Crashlytics Gradle plugin requirements.

## Required owner actions in Firebase Console

1. Register the Android and iOS apps under App Check.
2. Configure Play Integrity for Android; add the Play signing certificate fingerprints when the Play account/upload flow is ready.
3. Configure App Attest/DeviceCheck for iOS and confirm the Apple App Attest capability/signing environment.
4. Register debug tokens generated by developer/simulator builds; keep tokens out of Git and support tickets.
5. Confirm App Check metrics for legitimate app traffic before enabling Firestore/Auth/other product enforcement. The callable Cloud Functions already enforce App Check in deployed Functions; emulator execution is exempt.
6. Enable Crashlytics and Performance Monitoring for the project and verify a real release test device reports telemetry. Do not force a crash in a production user session.

## Web limitation

Web App Check is intentionally not initialized because no reCAPTCHA Enterprise site key was provided. Web distribution must remain disabled until a web App Check provider is configured and verified.

## Validation after applying

```bash
flutter pub get
dart format lib/main.dart
flutter analyze
flutter test
flutter build apk --debug
flutter build ios --simulator
```

Do not attempt a release build until the dedicated signing keystore is configured and Play Integrity/App Attest registration is complete.
